Algorithm usage

                    

                        
Stack

                        
Seat selection undo: push each change, pop to reverse it.

                        
Linked list

                        
Selected seats follow an array-based chain of indices.

                        
2D array

                        
The seating plan stores each seat at [row][column].

                        
Queue

                        
Persistent waitlist entries are enqueued in joining order; the curator dequeues the next
                            invitation.

                        
SHA-256 + salt

                        
Passwords use PBKDF2-HMAC-SHA256, random salts and 210,000 iterations. Tokens use SHA-256
                            digests.

                        
Text files

                        
Transaction events are appended to JSONL. Personal records can be read back and downloaded
                            from Wallet.
